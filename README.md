# UXUI-System-Design

## Project(s) Description
A portfolio showcasing UX design projects developed for my module, featuring a webpage design, interactive prototype/wireframes, and user persona. This project focused on creating a user-centered digital experience by applying UX research, wireframing, prototyping, and interface design principles to solve real-world user needs effectively.

---

## Objectives
- Design an intuitive and visually appealing webpage interface
- Develop interactive prototypes to demonstrate user flows and functionality
- Create detailed user persona based on target audience research
- Apply UX principles such as usability, accessibility, and user-centered design
- Strengthen practical skills in design thinking, prototyping, and digital product development

---

## Technologies Used
- Figma 
- Canva

---


## What I Learned
- Improved proficiency in Figma for professional UX/UI design
- Developed stronger understanding of user personas and audience analysis
- Learned how prototyping enhances usability testing and design refinement
